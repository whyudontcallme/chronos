# ⏳ Chronos

**3D-визуализация прокрастинации** — смотрите, как ваше время превращается в чёрную массу.

![Chronos Preview](./image_2026-03-30_23-47-12.png)

---

## 🔥 О проекте

Chronos — это минималистичное веб-приложение, которое визуализирует потерянное время в реальном времени. Создано для борьбы с прокрастинацией.

- 🎨 **Белая сфера** становится **чёрной** по мере того, как вы отвлекаетесь
- 🌍 **Двуязычный интерфейс** (EN / RU)
- 📱 **Полностью адаптивный** дизайн


## 🌟 Roadmap
